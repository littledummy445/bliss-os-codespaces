# Contributing to Bliss OS Codespaces

Thanks for your interest in improving this project.

## Getting Started

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes in small, focused commits.
4. Open a pull request with a clear summary of what changed and why.

## Development Notes

- Keep changes minimal and scoped to the task.
- Update documentation when behavior or usage changes.
- If you change `run-bliss-novnc.sh`, test it inside a Codespace before opening your PR.

## Pull Request Checklist

- [ ] My change is focused and does not include unrelated edits.
- [ ] I updated docs if needed.
- [ ] I tested my changes (when applicable).
- [ ] My PR description explains the change clearly.

## Reporting Issues

When filing an issue, include:

- What you expected to happen
- What actually happened
- Steps to reproduce
- Relevant logs or screenshots
